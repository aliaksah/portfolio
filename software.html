Software & Open Source

Officially published R packages on CRAN, Python tools in the spaCy Universe, and methodological implementations for scalable Bayesian inference and machine learning.

FBMS CRAN Package • R
Flexible Bayesian Model Selection and Model Averaging
A high-performance package for model selection and model averaging in generalized linear models (GLMs) and Bayesian generalized nonlinear models (BGNLMs). Implements mode jumping MCMC, subsampling MCMC, and genetic algorithm transformations for exploring complex non-linear feature spaces.
install.packages("FBMS")
CRAN Package JOCS Paper (2026) Tutorial (arXiv)
LBBNN CRAN Package • R
Latent Binary Bayesian Neural Networks Using 'torch'
Enables sparse, uncertainty-aware, and explainable deep learning by combining variational inference with latent binary variables and normalizing flows. Features input-skip connections to preserve interpretability and perform feature attribution in deep Bayesian neural architectures.
install.packages("LBBNN")
CRAN Package CRAN Manual (PDF) JAIR Paper (2026) R Journal Article
depmixS4pp GitHub • R
Adaptive Simulated Annealing EM for Hidden Markov Models
An extension of the standard depmixS4 package incorporating adaptive simulated annealing variable selection, non-homogeneous transition probabilities, and various forward prediction modes for complex time-series data.
# install.packages("devtools") devtools::install_github("aliaksah/depmixS4pp")
GitHub Repository ACM AIIPCC Paper
EMJMCMC CRAN Package • R
Evolutionary Mode Jumping Markov Chain Monte Carlo
An expert toolbox for Bayesian model search and variable selection in multimodal posterior distributions. Combines genetic algorithm crossovers and mutations with local mode optimization and MCMC transitions to escape local optima.
install.packages("EMJMCMC")
CRAN Package Bayesian Analysis Paper
skweak Python • spaCy
Weak Supervision Made Easy for NLP
A Python toolkit for gathering, combining, and aggregating noisy supervision sources (heuristics, regexes, gazetteers, and machine learning models) into high-quality training labels using Hidden Markov Models. Featured in the spaCy Universe.
pip install skweak
